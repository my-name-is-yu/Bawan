# 短い英語入力の翻訳プロンプト比較

2026-11-13。単語・熟語・短文の翻訳を、追加モデルや辞書を常駐させずに改善するための比較。

採用した処理は、EN→JPの1語では入力言語を`en`と明示し、2〜5語ではPFML3の`context`に「英語から日本語への翻訳です。」を加える。6語以上、JP→EN、英字を含まない入力、日本語混在などは通常のプロンプトを使う。長い指示や翻訳例の追加より小さく、選定用データでは最上位だった。

## 方法

- 保存済みのPLaMo 3 Translate 0.8B GGUF Q4_K_M、llama.cpp b12307、greedy生成を使用。
- モデルのSHA256は`70891ec70dc7ab4205745a38307867c2881b99239f20327927633abfe4bc9ec6`。
- 16候補を比較。最初は36件に10候補、その後は名詞・動詞・副詞も含む42件に9候補を比較した。
- 候補は、入力言語の明示、英語／日本語の補助文脈、意味の翻訳を促す指示、単語・熟語・短文の翻訳例、その組み合わせ。
- 候補の選定は、最終確認用24件の出力を見る前に固定した。最終確認後のプロンプト調整は行っていない。
- 各リクエストでKVとサンプラーをリセットし、入力ごとに候補を切り替えた。同一条件で再実行した出力に差はなかった。
- 別エージェントが候補名を隠した出力を評価した。2は意味が正しく実用的、1は意味が不完全または一般的な意味を読み取れない音写、0は誤訳。通常の外来語や固有名詞は許容し、文体や句読点の違いは採点しなかった。

AIによる少数例の意味評価であり、人による採点や標準ベンチマークの成績ではない。

[公式のPFML3仕様](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF#pfml3-prompt-format)に従い、補助文脈を原文とは別に渡す。原文は従来どおり特殊トークンとして解釈しない。

## 結果

表は「2：意味が正しく実用的」と評価した件数。

| 入力群 | 現状 | 採用候補 |
| --- | ---: | ---: |
| 選定用42件 | 36/42 | 40/42 |
| 最終確認用24件 | 21/24 | 23/24 |
| 長文・逆方向・固有名詞などの確認12件 | 12/12 | 12/12 |

選定用と最終確認用を合わせた内訳は次のとおり。

| 種類 | 現状 | 採用候補 |
| --- | ---: | ---: |
| 単語 | 21/26 | 25/26 |
| 熟語 | 16/20 | 18/20 |
| 短文 | 20/20 | 20/20 |

改善例は`ephemeral`の「エフェメラル」→「儚い」、`resilient`の「レジリエントな」→「強靭な」、`on the fence`の「フェンスの上」→「どっちつかず」、最終確認用の`hit the sack`の「仕事に行く」→「寝る」。

全ての短い入力が正しくなるわけではない。

- 最初に報告された`serendipitous`は、採用候補でも音写が残る。比較した全候補で正しい意味を出せなかった。
- `in hot water`は「お湯の中で」という直訳が残る。
- 最終確認用の`the last straw`は「最後の一押し」（部分的な意味）から「最後の一滴」（誤訳）へ悪化した。
- 全ての短い入力に英語の補助文脈と入力言語を指定する候補も選定用では同点だったが、`serendipitous`が無関係な「横向きの」になったため採用しなかった。

## 実装と確認

語数はモデルのトークン数から独立して数える。縮約形とハイフンでつながる語は1語、空白や句読点は区切りとし、6語目で通常経路に戻す。ASCII英字が最低1文字必要で、数字だけや未対応の非ASCII文字を含む入力は通常経路に戻す。Unicodeの引用符・アポストロフィ・一般的な空白などは扱える。

語数判定はメモリ確保なしで行う。モデル数、コンテキスト長8192、生成方式、履歴の保持方法は変えていない。新しい常駐プロセスや依存ライブラリはない。

- 語数・境界・混在文字など35ケースと、1語／複数語の分岐に使う語数を確認。
- `copy_gesture`と`short_english_input`のCTestに成功。
- 実装済みのエンジンで全78件が完了し、選定した比較候補と全て同じ出力になった。
- 実モデルの`engine_smoke`に成功。翻訳方向、KVリセット、入力制限、ストリーミング、キャンセルを確認。
- `Lore.app`をビルドし署名した。起動中の`/Applications/Lore.app`への差し替えは行っていない。
